# Minimum spanning trees and shortest paths (Chs. 7, 8 and 9)

Source: **JE** (*Algorithms*, Erickson, 2019). Pages = **PDF** (printed = PDF − 18). Ch. 7 = p.275-286 (exercises through p.290); Ch. 8 = p.291-308 (exercises through p.326); Ch. 9 = p.327-338 (exercises through p.344).

## 1. Minimum spanning trees (Ch. 7, JE p.275-286)
- `[from source]` Input: a connected, undirected graph with real weights $w(e)$ (positive, negative or zero); the MST minimizes $w(T)=\sum_{e\in T}w(e)$ (JE p.275).
- `[from source]` **Distinct weights ⇒ unique MST** (Lemma 7.1); the converse is false (JE p.276, note 1). The book breaks ties with a consistent criterion (`ShorterEdge`) and assumes distinct weights for the rest of the chapter (JE p.276-277).
- `[from source]` **"The only MST algorithm"**: maintain a forest $F$ that is a subgraph of the MST; an edge is useless (*useless*) if it joins two vertices of the same component of $F$, and safe (*safe*) if it is the lightest edge with exactly one endpoint in some component of $F$; the MST contains every safe edge (Lemma 7.2, due to Prim, valid for any subset $S$ of vertices) and no useless edge (Lemma 7.3) (JE p.277-279).
- `[from source]` **Borůvka** (1926): "add ALL the safe edges and recurse"; each iteration takes $O(E)$ and halves the number of components or better, hence $O(\log V)$ iterations and $O(E\log V)$ (JE p.279-281). Advantages mentioned: can be faster, parallelizable, $O(E)$ for planar graphs (a variation) (JE p.281).
- `[from source]` **Jarník ("Prim")** (1929): "repeatedly add the safe edge of the tree $T$"; it is a *best-first search*; with a binary heap $O(E\log E)=O(E\log V)$ (JE p.281-282). With a *Fibonacci heap* (Fredman-Tarjan, 1984) over the vertices: $O(E+V\log V)$, but "in practice it is rarely worth it" (JE p.282-283).
- `[from source]` **Kruskal** (1956): scan the edges by increasing weight; accept if the endpoints are in different components; *union-find* structure (`MakeSet`, `Find`, `Union`); the sort $O(E\log E)=O(E\log V)$ dominates; result $O(E\log V)$, the same as Borůvka and Jarník with a binary heap (JE p.283-286). With union by rank and path compression, $O(E\alpha(V))$ for maintaining the sets (JE p.285, note 6).
- `[inference]` The $O(V)$ memory of these structures and the "adjacency matrix" table for the MST are deductions, not from the book.

## 2. Single-source shortest paths, SSSP (Ch. 8, JE p.291-313)
- `[from source]` The book solves SSSP: shortest paths from $s$ to every vertex, represented by a *shortest-path tree*; the chapter treats only directed graphs (JE p.292-293).
- `[from source]` **Negative edges and cycles**: a shortest path from $s$ to $t$ exists if and only if there is a path and no path from $s$ to $t$ touches a negative cycle (JE p.293). In $\mathrm{APSP}$, $dist(u,v)=-\infty$ is defined in these situations (JE p.328).
- `[from source]` **Generic Ford algorithm**: `dist(v)`/`pred(v)`; an edge $uv$ is tense (*tense*) if $dist(u)+w(uv)<dist(v)$; relax (*relax*) the edge; repeat until there are no tense edges. It terminates with the correct tree if and only if there is no reachable negative cycle (JE p.294-295). All the variants below are instances of this (JE p.295-296).
- `[from source]` **BFS** for weights of 1: FIFO queue, phase lemma (each vertex is enqueued/dequeued at most once), $O(V+E)$ (JE p.296-299).
- `[inference]` "In an undirected graph every edge joins equal or adjacent levels" is not stated on these pages; it is a consequence of Lemma 8.1.
- `[from source]` **DAG**: in topological order, even with negative weights, $O(V+E)$ (JE p.300-302). It is DP: $dist(v)=\min_{uv}(dist(u)+w(uv))$ (JE p.300).
- `[from source]` **Dijkstra**: priority queue keyed by $dist(v)$ (JE p.302-303). *With nonnegative weights*: extracts in nondecreasing order, each vertex at most once, correct; $O(E\log V)$ with a binary heap (JE p.304-306); Dijkstra's original $O(V^2)$ (JE p.306, note 8); $O(E+V\log V)$ with a Fibonacci heap (JE p.306, note 8).
- `[from source]` **Dijkstra and negative edges — an important nuance**: the book distinguishes `Dijkstra` (with `Insert` at the first relaxation and `DecreaseKey`) from `NonnegativeDijkstra` (inserts everything at the start). **`NonnegativeDijkstra` does not compute correctly with negative edges** (JE p.306-307). The full `Dijkstra` remains correct for graphs **without negative cycles** (it is an instance of Ford's algorithm, JE p.304), but the same vertex may be extracted several times and the worst case is **exponential**: the Shier-Witzgall family forces $\Theta(2^{V/2})$ relaxations and another one, $\Theta(2^V)$ (JE p.307).
- `[inference]` A safe rule of thumb, consistent with the book: with negative edges use Bellman-Ford, the DAG algorithm (if it is a dag) or Johnson (APSP); do not use "textbook-standard" Dijkstra. Saying that "Dijkstra fails catastrophically with any negative edge" oversimplifies the book (that was the v1 text, p.301-304).
- `[from source]` **Bellman-Ford**: "relax all tense edges, repeat"; Lemma 8.6: after $i$ iterations $dist(v)\le dist_{\le i}(v)$; without negative cycles it terminates in $V-1$ iterations; if there is still a tense edge after $V-1$, there is a negative cycle; $O(VE)$ (JE p.309-310). Moore's version (queue, phases) with the same worst case $O(VE)$ (JE p.310-312). Formulation as DP (Bellman, table $dist[i,v]$) (JE p.312-313).
- `[inference]` The $O(V)$ space of Bellman-Ford is a deduction (only $dist$ and $pred$).

## 3. All pairs, APSP (Ch. 9, JE p.327-338)
- `[from source]` Output: $V\times V$ matrices of $dist$ and $pred$; boundary cases ($\infty$, $-\infty$, $dist(u,u)=0$) (JE p.327-328).
- `[from source]` $V$ single-source runs: BFS $O(VE)$, dag $O(VE)$, Dijkstra $O(VE\log V)$, Bellman-Ford $O(V^2E)=O(V^4)$ (JE p.328-329).
- `[from source]` **Adding a constant to all edges to eliminate negative ones does NOT work**: paths with more edges grow faster (Fig. 9.1) (JE p.329). What works is **reweighting by vertex prices**: $w'(uv)=\pi(u)+w(uv)-\pi(v)$ preserves shortest paths between every pair (JE p.329-330).
- `[from source]` **Johnson**: add $s$ with weight-0 edges to every vertex; Bellman-Ford from $s$ gives $\pi(v)=dist(s,v)$; $w'(uv)=dist(s,u)+w(uv)-dist(s,v)\ge0$; Dijkstra from each source; correct at the end with $dist[u,v]=dist'[u,v]-dist[s,u]+dist[s,v]$; abort if there is a negative cycle (JE p.330-331). Time $O(VE\log V)=O(V^3\log V)$ with a binary heap; with a Fibonacci heap $O(VE+V^2\log V)$ (JE p.329, note 3; JE p.330).
- `[from source]` Dynamic programming: Shimbel $O(V^4)$ (by number of edges $\ell$), Fischer-Meyer/Leyzorek $O(V^3\log V)$ (by "squaring" the size), connection to "min-plus" matrix multiplication (JE p.331-335). Strassen and variants do not apply because there is no "subtraction" in min-plus (JE p.335).
- `[from source]` **Floyd-Warshall** ("Kleene-Roy-Floyd-Warshall-Ingerman", 1962): $dist(u,v,r)$ = shortest path from $u$ to $v$ whose intermediate vertices have number $\le r$; $dist(u,v,0)=w(uv)$ and $dist(u,v,r)=\min\{dist(u,v,r-1),\ dist(u,r,r-1)+dist(r,v,r-1)\}$; $O(V^3)$, three loops with $r$ outermost (JE p.336-338). It removes the $\log V$ factor of Leyzorek (JE p.336).
- `[inference]` Choosing between Johnson and Floyd-Warshall: the book says FW is a factor $\log V$ faster than Leyzorek's DP and that Johnson with a binary heap costs $O(VE\log V)$ (JE p.330, 336); "Johnson for sparse graphs, FW for dense ones" is common practice `[extrapolation]`. The $O(V^2)$ space of FW is a deduction from the distance table (JE p.337-338).
