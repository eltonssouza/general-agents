# Fidelity and test report: git-version-control-expert

## 1. Scope and method

- Sources: PGEN (Pro Git EN 2.1.450, 501 pages) and PGBR (Pro Git PT-BR 2.1.47, 500 pages), text extracted with PyMuPDF per page (`=== PAGE N ===`). Page convention: PDF (printed PGEN = PDF - 6; PGBR = PDF - 5).
- Chapter-by-chapter reading (map) with intermediate notes saved per page range (PGEN: p.8-68, 69-110, 111-171, 172-223, 224-276, 277-341, 342-419, 420-458, 459-501; PGBR: p.10-250 and 251-500 for the glossary), done by subagents under a fidelity brief (only record what was seen on the page; extrapolation in its own section; CHECKS with substrings per page). Consolidation (reduce) done by the main agent: topic references, glossary, edition map, procedures, cases, scripts.
- All the text of the chapter references was derived from the notes; the lines with a page are what the subagent read on that page.

## 4. Fidelity errors found and corrected during the audit

1. **PT glossary (subagent):** claimed that "rebase interativo" does NOT appear in PGBR. The negative verifier failed: the term appears in PGBR p.143 (cross-reference). Fixed in `glossario.md`, in `git_lookup.py` and in the tests.
2. **SHA-256:** the initial text (and index/lookup entries) said the book "does not mention SHA-256". The EN cites "SHA256" in PGEN p.226 (note on the 2017 collision: Git is moving to SHA256). Fixed: the book only gives the passing note and does not teach SHA-256 repositories (the negative became `object-format`).
3. **Advisor/lookup:** wrong substring/token matching (e.g. "git worktree" matched "tree" from the internals topic; "undo published merge" matched "join branches"; "GitHub Actions" matched "GitHub"). Fixed with word boundaries, stopwords, and priority for the longest trigger phrase; cases F01, B06, P08 are now correct.
4. **Pages cited by the advisor itself:** I checked about 50 page/term combinations; 8 did not match, generally by 1 page (e.g. `reset --soft` p.267, not 266; `bisect reset` p.303 and `bisect run` p.304; `--recurse-submodules=check` p.316). Fixed or covered by a range; the rest became checks.
5. **Subagent notes:** the Ch. 8-9 note declared 6 corrections without re-running the validation; the final validation (all 957+ substrings) passed.
6. **Brief readability warning:** the brief anticipated that PT-BR accents would become U+FFFD; read as UTF-8 the file is intact (0 U+FFFD); the loss only occurs when printing to a cp1252 console. The verifier normalizes and reads UTF-8.

Manual spot-check readings (page text): PGEN p.255 (filter-repo recommended), 269 (reset --hard the only dangerous form), 106 (rebase rule), 115 (git:// arbitrary execution), 52 (Undoing Things), 289 (revert -m 1), 437 (dangling), 240 (git clean), 137 and 136 (commit message and diff --check), 226 and 76 (SHA256, switch), 336 (cleartext), 495 (revert = reverse cherry-pick), 370 (hook with ACL).

## 6. Content points of attention

- **[DATED]:** `master` as the default (PGEN p.29, 35, 87), `checkout`/`reset HEAD` as the main way to undo (restore only in p.55-56; Appendix C p.490 does not list switch/restore), `filter-branch` (the book itself discourages it, p.255), `git://` (p.115-116), HTTPS with password and GitHub Services (p.180, 214-220), `stash save` (p.236), Git Fusion/Google Code/git-remote-hg (Ch. 9), `am --resolved`, the `recursive` strategy, SHA-1.
- **PGBR:** translation only of the body up to p.188 and Ch. 10 (p.420-434) plus fragments; 189-419 in English. Inconsistent terminology (área de stage/preparo/preparação; merge/mesclagem/fusão; commits/commites). The section "Your default branch name" is missing in PT.
- **Book errors:** Ruby example of the ACL pre-commit hook with a badly closed block (PGEN p.370); `ref/heads/special-branch` in the webhook example (p.217); the book's commit examples do not follow the standard it recommends (p.137).
- Appendix C does not cite pages, only sections: the command -> page map was resolved by title (some ambiguous titles have an alternative indicated in `apendices-e-mapa-de-comandos.md`).

## 7. Honest limitations

- **The tests were not run "blind" by an independent model.** They were run by the author itself against scripts, references and the verifier; the agent's final natural-language answers were not evaluated by a second model.
- The reading of PGBR p.251-500 was partial: the language of each page was classified statistically (accents/function words) and confirmed by titles and excerpts, not by a full reading of the ~230 pages in English; the full reading covered PGBR p.10-189 and p.420-434.
- Figures and diagrams (Fig. 1-170 approx.) have no extracted text: only captions. The reset/merge logic illustrated in the figures was reconstructed from the text.
- There is reference content marked `[extrapolation]`/`[DATED]` written by subagents from general knowledge; it is labeled, but not verifiable against the PDF.
- The automatic verification confirms terms per page; complex paraphrases may contain inaccuracies that only reading detects (the manual spot checks in section 4 sample the highest-risk points).
