## 2. Page convention (declared and uniform)

- **Page = PDF page number** (the "=== PAGE N ===" marker of the extracted text). PGEN printed page = PDF - 6 (e.g. printed Introduction 8 = PDF 14); PGBR = PDF - 5.
- The two editions do NOT have the same pagination (PGBR = PGEN minus 4 to 9 up to Ch. 7; see `edicao-ptbr-e-numeracao.md`). Always cite `(PGEN p.N)` and, when useful, `(PGBR p.N)`.
- The PGEN Index (PDF 499-501) and the table of contents (PDF 3-6) use printed pages.
- The extracted text is intact in UTF-8 (accents correct in PGBR). Windows terminals in cp1252 show "?" in place of accents: use UTF-8.
