# Glossary (only terms the notes use)

Convention: `(R3x p.N)` = PDF page of the note. Terms the notes do not explain are marked `[extrapolation]`.

- **Optcarrot** (R30 p.1): NES emulation benchmark that measures single-thread performance.
- **Ruby 3x3** (R30 p.1): goal of making Ruby 3 three times faster than Ruby 2.
- **MJIT** (R31 p.1-2): method-based JIT that uses an external C compiler; entered Ruby 2.6; replaced by RJIT in 3.3 (R33 p.4). `[DATED]`
- **YJIT** (R31 p.1-2): Shopify's in-process JIT, based on Basic Block Versioning; production-ready in 3.2 (R32 p.4).
- **LBBV** (R31 p.2): Lazy Basic Block Versioning; compiles the start of the method and the rest incrementally.
- **RJIT** (R33 p.4): pure Ruby JIT, x86-64 Unix, experimental.
- **Code GC** (R32 p.4; R33 p.3): collection of the code generated by YJIT; on in 3.2, off by default in 3.3.
- **Object Shapes** (R32 p.4; R33 p.5): mechanism mentioned as the basis of optimizations (`defined?(@ivar)`, YJIT). `[extrapolation]` as to its internal workings.
- **Ractor** (R30 p.2): actor-like concurrent abstraction, experimental in 3.0.
- **Fiber Scheduler / `Fiber#scheduler`** (R30 p.3): intercepts blocking operations.
- **M:N threads** (R33 p.4): M Ruby threads over N native threads.
- **RBS** (R30 p.4): language for describing types of Ruby programs.
- **TypeProf** (R30 p.4-5): generates RBS prototypes from code without annotations.
- **Pattern matching** (R30 p.5-7): `case`/`in`, `=>`, `in` (returns boolean), find pattern, pin `^`.
- **Pin `^`** (R31 p.5): in 3.1 it accepts an expression.
- **Endless method** (R30 p.6): `def f(x) = expr`.
- **Argument forwarding `...`** (R30 p.7): in 3.0 it accepts leading arguments.
- **`Data`** (R32 p.11): simple immutable value class.
- **ReDoS** (R32 p.5): denial of service through a slow regex against untrusted input.
- **Memoization (in regex matching)** (R32 p.5): technique of the new 3.2 algorithm.
- **`Regexp.timeout`** (R32 p.7): global timeout; `timeout:` per regex; `Regexp::TimeoutError`.
- **`error_highlight`** (R31 p.3): refined error location in the backtrace.
- **`syntax_suggest`** (R32 p.8): helps find a missing or extra `end`; previously called `dead_end`.
- **debug.gem** (R31 p.2): rewritten debugger.
- **WASI** (R32 p.1-2): WebAssembly system interface.
- **Asyncify** (R32 p.3): binary transformation technique used by CRuby for Wasm.
- **Prism** (R33 p.1): recursive descent parser, error-tolerant; default in 3.4 (R34 p.2).
- **Lrama** (R33 p.2): LALR parser generator that replaced Bison.
- **Happy Eyeballs v2** (R34 p.2): RFC 8305 connection algorithm in `TCPSocket.new` and `Socket.tcp`.
- **Modular GC** (R34 p.4): loading alternative GC implementations (`RUBY_GC_LIBRARY`).
- **default gem / bundled gem** (R31 p.8-11; R34 p.7): categories of gems distributed with Ruby; several move from one to the other between versions.
- **GVL, YARV, Onigmo, Steep, DAP** `[extrapolation]`: **do not appear** in the five notes; do not attribute to the source. `byebug` only appears inside `pry-byebug`, when describing `irb:rdbg` (R33 p.6); "`debug` replaces byebug" is not stated.
