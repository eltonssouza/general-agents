# Glossary (terms that appear in the captures)

Definitions are what the **text of the Overview** says, in paraphrase; they are not complete technical definitions. Terms explained beyond that are `[extrapolation]`.

| Term | What the Overview says | Where |
|---|---|---|
| Angular | Google web framework for fast, reliable apps | NG18 p.1; NG21 p.1 |
| Component | splits the code into encapsulated pieces | NG18 p.1; NG21 p.2 |
| Dependency injection | keeps code modular/decoupled/testable (NG18-NG20); shares code between components (NG21/NG22) | NG18 p.1; NG21 p.3 |
| Signals | basis of fine-grained reactivity | NG18 p.1; NG21 p.2 |
| Fine-grained reactivity | tracks where/how state is used, for fast updates | NG19 p.3; NG20 p.2 |
| SSR | server-side rendering | NG18 p.2; NG21 p.3 |
| SSG | static site generation | NG18 p.2; NG21 p.3 |
| Hydration | "full DOM hydration" cited together with SSR/SSG | NG18 p.2; NG21 p.3 |
| `@defer` | blocks in templates to split them into pieces that load on demand (only NG18-NG20) | NG18 p.2; NG19 p.3; NG20 p.2 |
| Router | route guards, data resolution, lazy-loading | NG18 p.2; NG21 p.3 |
| Forms | standardized form participation and validation | NG18 p.2; NG21 p.3 |
| CLI | project running in under a minute through to production | NG18 p.2; NG21 p.3 |
| DevTools | component inspector, DI tree, flame chart | NG18 p.2; NG21 p.4 |
| `ng update` | automatic code transformations for routine breaking changes | NG18 p.3; NG21 p.4 |
| Language service | IDE features: complete, navigate, refactor, diagnose | NG18 p.3; NG21 p.4 |
| LTS | long-term support windows with critical security fixes (no dates) | NG18 p.3; NG21 p.5 |
| ICU | Unicode standard syntax used in i18n | NG18 p.4; NG21 p.5 |
| Trusted types / HTML sanitization | built-in security features against XSS and CSRF | NG18 p.4; NG21 p.5-6 |
| Vite, esbuild | CLI build pipeline | NG18 p.4; NG21 p.6 |
| NgOptimizedImage | built-in performance optimization, born from the partnership with Aurora (only cited) | NG18 p.5; NG21 p.8 |
| Core Web Vitals | metrics that the Aurora partnership seeks to improve (only cited) | NG18 p.5; NG21 p.8 |
| RFC | request for comments for larger changes | NG18 p.4; NG21 p.6 |
| GDE | Google Developer Expert, community leader | NG18 p.5; NG21 p.7 |
| doc-capture | (our term) PDF that is a capture of a web page, with interface noise | INDEX §1 |
