# Glossary (terms as they appear in the sources)

Acronyms: **NX13/NX14/NX15/NX16** = Next.js 13 to 16 release posts; **NXHB** = Next.js Handbook (2019, [DATED]); **RCTHB** = React Handbook (2020, [DATED]). Pages = PDF page.

| Term | Meaning according to the collection | Where |
|---|---|---|
| app/ (App Router) | Route directory with layouts, Server Components and streaming; beta in NX13, the basis of NX14-NX16 | NX13 p.2-5 |
| pages/ (Pages Router) | Classic route directory; stable in NX13; accepts React 18 and 19 in NX15 | NX13 p.2; NX15 p.5-6; NXHB p.4 |
| Server Component | Component rendered on the server, the default in app/; reduces client JS | NX13 p.4 |
| Server Action | Server function called from components, `'use server'` directive; stable in NX14; treat as a public endpoint | NX14 p.4-5; NX15 p.13-14 |
| loading.js | Special file that creates an Instant Loading UI via Suspense; cached 5 min in the client router cache (NX15) | NX13 p.7; NX15 p.5 |
| Partial Prerendering (PPR) | Static shell + dynamic streamed parts defined by Suspense; preview in NX14; evolves into Cache Components in NX16 | NX14 p.5-7; NX16 p.3 |
| Cache Components | Opt-in cache model with `'use cache'`, enabled by `cacheComponents: true` | NX16 p.2-3 |
| `'use cache'` | Directive that caches pages, components and functions; keys generated by the compiler | NX16 p.2 |
| cacheLife | Revalidation profile (`'max'`, `'hours'`, `'days'`, or `{ expire }`) required as the 2nd argument of `revalidateTag` | NX16 p.9 |
| updateTag / refresh | Server-Actions-only APIs: read-your-writes and refreshing uncached data | NX16 p.10-11 |
| Client Router Cache | Client-side navigation cache; `staleTime` 0 for Page segments in NX15 | NX15 p.5 |
| Turbopack | Rust bundler; alpha (13), stable in dev (15), default in dev and build (16) | NX13 p.7; NX15 p.8; NX16 p.6 |
| proxy.ts | Replaces `middleware.ts` in NX16; Node.js runtime | NX16 p.4 |
| Middleware | Request interception code; file name deprecated in NX16 | NX13 p.13-14; NX16 p.14 |
| Async Request APIs | `cookies`, `headers`, `draftMode`, `params`, `searchParams` become async | NX15 p.3-4; NX16 p.12 |
| @next/codemod | CLI of automatic upgrade transformations | NX15 p.2-3 |
| instrumentation.js / register / onRequestError | Server lifecycle hooks for observability | NX15 p.10-11 |
| unstable_after | Experimental API to run code after the response | NX15 p.9-10 |
| next/form | `<Form>` component with prefetch, client navigation and progressive enhancement | NX15 p.11-12 |
| React Compiler | Compiler that memoizes automatically; experimental (15), stable but opt-in (16) | NX15 p.6-7; NX16 p.7-8 |
| Build Adapters | Alpha API to adapt the build | NX16 p.7 |
| DevTools MCP | Model Context Protocol integration for AI-assisted debugging | NX16 p.3-4 |
| getInitialProps | Data function of the classic Pages Router (NXHB); the releases do not mention it | NXHB p.56-61 |
| styled-jsx | Scoped CSS in JSX, built into the 2019 Next | NXHB p.61-63 |
| API Routes | Endpoints in `pages/api` | NXHB p.68-72; NX14 p.2 |
| create-react-app | The RCTHB's tool for creating React projects | RCTHB p.6-7 |
| useState / useEffect | Hooks presented in the RCTHB | RCTHB p.25, 32 |
| JSX | HTML-like syntax inside JavaScript | RCTHB p.14-24 |
