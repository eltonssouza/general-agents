# Glossary

Terms from the two sources, in alphabetical order of the original Portuguese entries, explained in the collection's own words. `WAI p.N` = PDF page; `NDDB p.N` = printed page.

### Web accessibility
Designing and developing sites, tools and technologies so that people with disabilities can perceive, understand, navigate, interact and contribute (WAI p.3).

### ATAG
Abbreviation of *Authoring Tool Accessibility Guidelines*; the source only cites it as a W3C resource, without explaining it (WAI p.5). `[from source (pointer only)]`.

### ARIA
*Accessible Rich Internet Applications*; cited only by name among the W3C standards (WAI p.5). Technical content absent from the sources.

### Alignment
One of the four principles of the NDDB (chapter starting at p.33; summary p.54). In the sample it appears only in the index mentions and in the example on p.65 (NDDB p.6, 65). The book's definition is **not** in the sample.

### Aligning at the top ("hanging from a clothesline") vs. at the bottom ("bottoming out")
Two techniques for anchoring text on the page; the book asks to choose one and be consistent (NDDB p.58).

### Authoring tools
One of the components that must work together for the web to be accessible, alongside web technologies, user agents and sites (WAI p.5).

### Accessibility barrier
A design or code characteristic that makes use difficult or impossible for some people (WAI p.1-2).

### Visual key
A repeated element strengthened enough to tie the publication together (idea from NDDB p.55; term in the collection's own translation).

### Consistency
In long publications, the everyday name for repetition (NDDB p.55, 68).

### Contrast (Principle of Contrast)
The fourth principle of the book (chapter starting at p.69; summary p.84). In the sample, only as a pointer and a mention on p.65 and p.68. It is **not equivalent** to color contrast as an accessibility requirement (a concept outside the sources).

### Temporary disabilities and situational limitations
Passing conditions (broken arm, lost glasses) or environmental ones (bright sunlight, unable to hear audio) in which people without disabilities also benefit from accessibility (WAI p.3).

### Designer Eye
Exercises in the book in which the reader names design elements; suggested answers are outside the sample (NDDB p.62-64).

### EOWG
Education and Outreach Working Group, which developed the WAI page (WAI p.7).

### White space
Index term; "by-product of organization" on p.32 and 142 (NDDB p.236-239). Content absent from the sample.

### Rule
A drawn line; an example of a repeated element, e.g. from 1 point to 4 points (NDDB p.55, 68).

### ISO/IEC 40500
The ISO standard that corresponds to WCAG 2.2 according to the source (WAI p.5).

### Situational limitation
See "Temporary disabilities".

### Naming the problem
The book's premise: giving a name to what is wrong makes it possible to fix it (NDDB p.10).

### Package / identity
A set of related pieces (card, letterhead, envelope) that should repeat elements among themselves (NDDB p.60).

### Proximity
First principle in the table of contents (chapter starting at p.15; summary p.32). Definition absent from the sample (NDDB p.6).

### Four basic principles
The book's recurring concepts: Proximity, Alignment, Repetition, Contrast (names in the table of contents, NDDB p.6; premise in NDDB p.10).

### Repetition
Repeating some visual aspect throughout the whole piece to unify it and add interest (NDDB p.55, 68).

### Surprise
A different element inserted in a consistent publication to draw special attention (NDDB p.59).

### Assistive technologies
There is no definition in the sources. A term outside the extracted vocabulary; if used, it is **[extrapolation]**.

### UN CRPD
The UN Convention on the Rights of Persons with Disabilities, which defines access to ICTs, including the web, as a basic human right (WAI p.4).

### User agent
A browser or other software that accesses web content; one of the components of accessibility (WAI p.5).

### WAI
The W3C *Web Accessibility Initiative*: develops accessibility specifications, guidelines, techniques and resources (WAI p.5).

### WCAG
*Web Content Accessibility Guidelines*; the source cites version 2.2, also ISO/IEC 40500, and a *Quick Reference* (WAI p.5-6). `[DATED]` as to the version. Criteria are **not** in the sources.

### Unity with variety
An idea from NDDB p.67: elements can vary if there is enough repetition structure (the term "unity with variety" appears in the index, NDDB p.238).
