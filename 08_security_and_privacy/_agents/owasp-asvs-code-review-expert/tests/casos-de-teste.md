How they were run: **by the package author**, one by one, against the agent prompt + `references/` + `scripts/` (running the scripts when the case calls for it). ## Test notes
- In T01 the source is ambiguous (health appears at L2 and L3): the agent must expose the tension and decide by risk, not pick a level by rule.
- In T07 and T16 the linter produces **candidate findings**; the agent must triage manually and never declare "code is safe" from the absence of findings (OCRG p.11).
- In T19 the correct conversion avoided the most likely mistake (confusing printed with PDF).
