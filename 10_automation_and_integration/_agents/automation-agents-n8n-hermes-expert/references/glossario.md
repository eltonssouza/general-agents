# Glossary (only what the sources say)

Each term carries what the source states, without adding knowledge from memory.

| Term | What the source says | Where |
|---|---|---|
| fair-code | adjective for the n8n license; the terms are not explained; there is a "Sustainable use license" link | N8N p.1, p.3 |
| workflow | n8n is a "workflow automation tool"; "Build your first workflow" is only a title | N8N p.1-2 |
| Expressions / Flow logic / Executions | only key-concept titles | N8N p.2 |
| Nodes / Connect / Deploy / Build | only menu tab names | N8N p.1 |
| MCP server (n8n) | n8n is connected to Claude Desktop, Claude Code and Codex CLI through an "n8n MCP server" (URL /mcp-server/http) | N8N p.3 |
| Schedule Trigger | label of a node in an image (render only) | N8N p.2 |
| Hermes Agent | AI agent from Nous Research; "self-improving"; autonomous | HERMES p.1-2 |
| Nous Research | lab behind Hermes, Nomos and Psyche | HERMES p.4 |
| learning loop | create skills from experience, improve them during use, persist knowledge, model the user | HERMES p.1, p.3 |
| skill | "procedural memory the agent creates and reuses"; compatible with agentskills.io; Skills Hub | HERMES p.3-4 |

| Tool Gateway | four tools: web search, image generation, TTS, browser | HERMES p.2 |
| Nous Portal | provider cited for model/tools and a single subscription; no details | HERMES p.2, p.4 |
| terminal backends | local, Docker, SSH, Daytona, Singularity, Modal | HERMES p.3 |

| Messaging Gateway | one gateway for 20+ messaging platforms | HERMES p.2, p.4 |
| FTS5 / Honcho | named in the learning loop; no explanation | HERMES p.3 |
| execute_code | "Programmatic Tool Calling" that condenses pipelines into single calls | HERMES p.4 |
| SOUL.md | global file that defines Hermes's default voice | HERMES p.3 |
| llms.txt / llms-full.txt | machine-readable entry points to the Hermes doc | HERMES p.4 |
| Atropos | used for RL training ("research-ready") | HERMES p.4 |
